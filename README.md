# Colytra Reborn

Unofficial port of [Colytra](https://github.com/TheIllusiveC4/Colytra) by C4 to NeoForge 1.21.1.

Attach an elytra to any chestplate in a crafting grid and wear both at once. Craft the chestplate on its own to take the elytra off again. Requires [Caelus API](https://github.com/TheIllusiveC4/Caelus).

The mod id (`colytra`) and the config are the same as the original.

## Building

```
./gradlew build          # also runs the game tests
./gradlew runClientSmoke # renders a player and an armor stand wearing one, then quits
```
